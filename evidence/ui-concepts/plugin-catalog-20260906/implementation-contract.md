# C 版实现契约

用户选择 C。保留选中原图；按用户明确要求优先遵循全站字号与间距，图中放大的顶栏、图标、字体不转成页面私有参数。

桌面卡片采用36px图标、文字、状态/操作三列，16px内边距、12px圆角、至少112px高度、16px栅格间距；正文14px、标题16px、控件13px。窄屏改单列，480px以下操作移到文字下方，卡片随文字自然增高。保留A版侧栏。

名称、短用途、一个待接入状态或使用按钮是全部可见卡片内容。公开资料范围保留；能力及原说明元数据仍在清单中供搜索与后续用途使用。可用插件走现有onSelect；仅官网知识可用，其他插件没有操作控件。已选状态继续由会话选择器展示，目录按钮不伪装为安装或开关。

素材：沿用PluginIcon/WorkbenchIcon SVG及共享CSS，不新增位图，不使用概念图充当界面。样式集中在cloud.css中的目录定义，清除cloud-modern.css中重复覆盖及被删除内容的样式。

验收包括桌面/窄屏、卡片内部溢出、保留隐藏能力关键词搜索、键盘选择、执行中禁用、空搜索、延迟/失败重连、文字200%和长标题压力检查。与原图比较同尺寸1576×998的内容区域截图；默认像素门槛如有偏差如实记录，不为满足生成图而放大公共尺寸。
