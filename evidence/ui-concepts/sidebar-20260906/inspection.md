# 侧栏概念检查

目标：云端 `/harness/` 的 `packages/ui/src/cloud/App.tsx` 侧栏；延续此前云端插件截图上下文。未开始产品代码修改。

参考原始尺寸为 1280×720，机器测量见 `reference-analysis.json`。侧栏宽 240px，主面板从 x=240 开始、顶部 y=12，顶栏 52px。主体采用浅灰底、白面板、蓝色强调；侧栏按 13px 控件与 12px 辅助文字设计。主页面维持 14px 正文、16px 卡片标题、16px 卡片 padding。

当前角色：品牌首页、会话/插件导航、新建、历史搜索、历史列表、访客授权状态、官网。现有导航与新建/历史分成不连贯的层级，底部身份和官网各占独立纵向区块。三版只调整这些角色的排列，不添加未接入功能。

邻页：已检查上一轮同版本会话空态、插件页与本地工作台截图。概念显示四条示例会话用于评估列表密度，最终实现仍用真实会话。

素材：只使用仓库既有 Aurora Fold Logo；标准图标、控件、分隔线均可由 DOM/CSS/SVG 实现，没有需要新增的装饰位图。Logo 最终必须引用原文件，不能截取概念图中的近似标志。

方案差异：A 是操作优先的单列；B 是 48px 全局导航栏加 192px 会话栏；C 是空间信息在顶部的单列分段导航。所有方向共享全站样式参数。等待用户选择后再进行实现、截图比较与交互验收。

## 生成后检查

三张图均已目视检查，完整展示品牌、导航、创建、搜索、历史、授权身份及官网，构图分别为单列操作优先、双区导航、空间优先的分段单列，无新增业务能力。右侧插件页仅作风格上下文。
