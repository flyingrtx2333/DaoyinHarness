# A 版实现契约

用户已选择 A。保留 `selected-reference.png` 原图，不覆盖其内容。

优先级：用户明确要求的全站一致性与 `docs/UI-STYLE-RULES.md` 高于生成概念中的尺寸偏差。最终侧栏采用 240px；在 900px 以下沿用现有 208px 响应式布局，手机沿用抽屉。桌面正文 14px、导航 13px、辅助 12px、控件至少 36px，触屏至少 44px。原图的 364px 侧栏及较大字号不是新的样式规范。

结构顺序：品牌 → 白底描边的新建会话 → 会话/插件导航 → 分隔线 → 最近会话标题/数量 → 搜索 → 可滚动历史 → 底部空间状态和官网同排。图标与文本沿共用列对齐。历史多时仅历史列表滚动，顶部操作和底部状态保留。

资产映射：`.brand-mark img` 使用已有 `packages/ui/public/assets/harness-logo.png`，经 `HarnessLogo` 加载；导航和会话图标使用 `WorkbenchIcon`；加号、外链标记、文字、输入、按钮及表面均由 DOM/CSS/SVG 构成，无额外生成位图。

动态数据：会话名称、数量、授权时间、选中态继续来自 API；概念中的四条示例只用于明确标记的浏览器 fixture，不进入产品。搜索空结果显示“没有匹配的会话”。保留新建、切换、筛选、插件选择、重连与移动导航功能。

验收：同尺寸 1672×941 截图与选中概念对照，保留原始差异报告，不声称像素复刻通过；另用布局断言确认归一到共享参数后的顺序、240px 宽度、底部合并和长列表滚动。覆盖 1280×720、390px、320px、会话与插件页、空/多会话、长标题、搜索和键盘焦点。
