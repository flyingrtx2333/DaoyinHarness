## 布局与交互

- 桌面采用单侧栏：新对话、搜索、当前工作区、任务状态、历史会话、连接状态和账号。侧栏可收起。
- 对话采用白底阅读区。用户消息、助手回答、工具状态和权限请求使用独立层级；输入框固定在工作区底部。
- 工作区文件与任务状态按需展开；`Escape` 关闭并恢复焦点。手机端通过左上角菜单展开会话导航，Tab 焦点保留在打开的导航内。
- 「仔细规划」仍传递现有 `planning` 参数；执行中显示停止按钮。分叉与恢复沿用原接口。
- 空白页的任务灵感仅填入输入框，由用户发送；未登录时不允许发送模型任务。
- 回答可复制为原始 Markdown。复制失败时显示可操作的提示。

## 工作区管理

侧栏当前目录旁的「切换」或文件面板中的「选择或切换工作区」打开管理窗口。可输入已有本机文件夹的完整路径，也可通过 Windows 文件夹窗口选择候选目录，再点击「打开工作区」。最近打开的 20 个目录可直接返回，支持中文和空格路径。切换会刷新页面并清空未发送的草稿。

每个工作区拥有独立的会话目录；返回原工作区会恢复原会话。切换重新绑定文件工具、进程目录、Skills 和资源权限，关闭旧的浏览器与事件连接。任务或其他请求进行中会拒绝切换并提示；不存在的目录不会被创建。其他旧页面会提示刷新，不能继续向新工作区发送操作。启动默认恢复最近可访问目录，显式 `--workspace` 优先。

默认递归文件列表和搜索忽略 `.git`、`node_modules`、`.venv`、`__pycache__`、`.cache`、`coverage`、`dist`、`build` 与禁止访问的参考源码目录。安全的显式相对路径读取保持原有边界。存储设计见 [ADR 0004](adr/0004-workspace-switching.md)。

## Markdown 与数据边界

`MarkdownMessage` 使用 `react-markdown` 和 `remark-gfm` 渲染标题、列表、引用、代码块与表格。代码和宽表格在自身区域滚动。原始 HTML 不执行；链接仅允许 HTTP、HTTPS、mailto 和页内锚点，外链隔离打开。图片仅显示替代说明，不因回放对话而请求外部图片。

会话正文、文件数量、账号和任务进度均来自运行时。概念图中的资料、时间、进度、反馈按钮和额外模型选项不构成后端功能，也不会作为固定假数据加入产品。界面使用独立编写的 SVG 标记、标准图标和 CSS；没有将概念图作为网页背景。

## 验证

遵循仓库约定，在 Windows PowerShell、Node.js 22 下运行：

```text
npm run typecheck
npm run lint
npm test
npm run build
node scripts/verify-workbench-ui.mjs
node scripts/verify-workspace-ui.mjs
node scripts/verify-native-folder-picker.mjs
```

浏览器脚本默认连接 `http://127.0.0.1:4677`，可通过 `HARNESS_UI_ORIGIN` 指定地址。构建之后启动本地服务再验收；已有服务需要重新启动才能注册新生成的静态资源文件名，重启前须确认没有运行中的任务。

浏览器验证包括两种明确区分的证据：真实本地运行时只读截图，以及由模拟 API/WebSocket 驱动的真实 Edge 界面交互。模拟覆盖搜索、复制、导航焦点、文件、任务、规划参数、授权拒绝及允许、重复提交、取消、断线重连、刷新回放、分叉、恢复、未登录跳转和服务错误态。不会调用付费模型或改写用户会话。

截图覆盖 1586×992、1280×720、768×1024、390×844 和 320×740。概念、选定参考、截图、像素差异、素材映射与验证结果保存在 [本轮证据目录](../evidence/ui-concepts/agent-workbench-redesign-20260905/)。其中 `render-live.png` 为真实本地数据，`render-desktop.png` 为明确标记的界面测试数据。此前 `verify-canvas-ui.mjs` 对应旧 C 版布局；当前界面使用新的工作台验证脚本。

这些检查证明本地界面行为，不代表真实模型质量或生产发布验收。

`verify-workspace-ui.mjs` 在 4698 端口启动独立数据目录的真实本地服务；模型回答和原生选择器返回值为注入测试。它验证文件面板入口、选择/取消、无效路径、执行中禁止切换、新旧目录与会话隔离、旧页面提示、最近工作区恢复及手机弹窗。结果与截图位于 `evidence/workspace-management/`，不会改写用户运行时的会话。

`verify-native-folder-picker.mjs` 会短暂打开真实 Windows 文件夹窗口，观察本次测试子进程的可见窗口并关闭，验证取消返回空路径。选定目录的完整 UI 流程由上面的本地浏览器测试验证；这项原生窗口检查不代表人工选目录验收。
