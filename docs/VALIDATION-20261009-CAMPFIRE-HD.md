成片 `res_d6094a204ed3468e4d6af14b`，计划 `res_8f3847816cae184bb2ce313f`，快照 `snp_afaeabb4279f44b8358a6027`。MP4为19.008秒、1080×1920、30fps、H.264，音频为AAC / 48kHz / 双声道，12,068,873字节。账号实际下载文件的 SHA-256 `6ee6d3fcc5017d6317a9a4cf825118a11b6c597e1f216e52d252f831e171df22` 与保存回执一致。完整音视频解码无错误；音频平均电平−17.6dB、峰值−1.4dB，不是静音音轨。

真实 Chrome 在约1200px桌面和390×844窄屏检查素材库、预览、下载入口与播放。视频实际播放至19.008秒结束，播放器错误为空。抽帧核对入口、上菜、菜品特写、圆桌和大厅均来自本店，混合模糊背景与主体裁切，字幕可见。预览播放器的侧边留空不是成片内编码黑边。没有声称逐帧人工质检或独立听审通过。

对照原营火样片：原片27.1秒，同为1080×1920 / 30fps，主要使用模糊背景。新片19.008秒、8镜头，混合裁切，5句旁白；声线、字幕节奏和文案不同。新片已有真实配音、配乐和高清剪辑，但不能称为相同质量、相同时间结构或完全复刻。原片中未确认的开业、套餐、价格等没有搬入本店事实。

四个实际 run 的已计价记录合计 **3.00143400 CNY**；42条用量中17条未完整计价，包含5条旁白记录的 `UNCONFIGURED`。因此该数不是完整供应商费用或账号总扣费；当前语音网关有账号额度检查和真实用量记录，**尚不能声称配音已完成结算扣费**。续做未新增旁白调用，五条原音频记录保持唯一。

证据保存在忽略的 `.cache/dongbeihui-live/`：实际输入、连续事件、诊断、回执、视频、抽帧、核验和用量 JSON。代码静态检查与精确提交打包已完成，它们不代替上述真实场景。
