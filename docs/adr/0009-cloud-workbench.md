# ADR-0009：独立云端工作台

日期：2026-09-05。状态：采纳。

工作台在官网同源 `/harness/` 提供独立全屏入口，复用已经上线的平台 Cookie/CSRF BFF
和同一 AgentEngine。首个可用应用为官网公开知识，界面明确显示访客空间、授权期限与只读工具。
不把本地回环服务、文件系统、进程权限或操作系统登录接口直接暴露到公网。

本地工作台与云端工作台采用独立入口和传输适配，复用 React、Markdown 渲染与视觉语言。
云端提供会话选择/搜索、任务对话、执行进度、资料引用、取消、分页事件回放和刷新恢复。
当前访客授权仍为 30 分钟；不把临时访客会话描述为登录账号的永久历史。
个人/企业空间、跨设备历史与业务写工具须在平台授权适配完善后接入。

凭据只在平台 HttpOnly Cookie 中。浏览器仅在 sessionStorage 保存会话标识和不确定提交的请求回执。
提交前保存 requestId 和正文；不确定结果由用户点击恢复，用相同编号/正文查询或重发，
不自动生成新编号重复调用模型。回放按事件序号去重，切换会话后丢弃旧视图请求的迟到响应。
过期授权清空可见受保护视图，明确要求重新进入；不自动继承旧授权数据。

发布只包含工作台静态资源，通过 Nginx 独立 location 提供，不覆盖官网 dist。
从已提交源代码构建，发布文件名带内容摘要，保留历史静态资源供旧标签页使用；入口原子切换。
部署前后验证同源 BFF、真实任务、刷新/切换、取消及桌面/移动布局。保留版本与回滚记录。
