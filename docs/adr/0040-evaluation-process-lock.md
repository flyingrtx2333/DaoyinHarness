# ADR-0040: 审计服务移除定时租约

状态：已采纳（2026-10-10，用户要求去掉租约）

评估服务仍以单实例运行，但不再创建、读取或续期数据库中的运行租约。旧 `evaluation_lease` 表保留为历史兼容数据，不参与鉴权、健康检查或审计查询。移除续期定时器；存储可用性只检查连接是否关闭。

systemd 启动命令使用 `flock --nonblock --no-fork` 持有独立评估目录内的进程锁。锁由操作系统在进程退出时释放，无有效期、续期或定时心跳。所有生产实例必须使用同一锁路径启动；这不是分布式调度方案。现有评估任务的幂等键、单活动任务唯一索引、SQLite 写事务、管理员鉴权和调用预算继续生效。

只切换独立评估服务，不重启 Agent、主平台或资源服务，不改写历史会话。实际验收检查真实审计接口、超过旧 30 秒有效期后的查询及第二个实例锁获取失败；不调用模型、运行模拟测试或启动评估任务。
