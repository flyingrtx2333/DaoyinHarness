# ADR-0017：超级管理员测试评估工作台

2026-09-06。用户要求在插件页面增加可视化测试入口，仅超级管理员可访问。

## 决策

- 在 Harness 云端「插件」页面内增加「插件目录 / 测试评估」标签，不新增面向普通用户的 Agent 工具。入口由主平台独立的超级管理员能力探针决定，不能用本地 storage、客户端角色字段或 tenant.manage 代替服务端检查。
- 主平台用已有 HttpOnly 账号 Cookie 解析用户，并实时查询有效的全局 roles(tenant_id=0,role_key=admin)、成员角色、用户和租户状态。普通企业 admin 和被授予 tenant.manage 的账号均不满足此条件。所有历史、详情、启动、取消、报告接口重复检查；写操作还验证 Origin、绑定当前账号会话的 CSRF 和账号指纹。
- 独立 Harness evaluation 服务接收主平台服务鉴权及服务端操作者 ID。与正常运行时分进程、分存储、分凭据；不持有生产业务数据库、上传存储或普通模型供应商凭据。
- 用例 = 原始输入 + 选定场景 + 预先确认的成功条件。首次交付批量最多 50 题、每题 1–5 次。未知题可以探索执行，但没有已确认标准的输出不自动计成功。
- 复用现有 Builder 评估中的模式区分、幂等、不可变实验配置和独立判分约定，但被测实现必须是 Harness 的 createCloudServer/AgentEngine，不调用 Builder Agent、不把回放答案当现场模型能力。
- 模式一为程序回放，用于协议/工具循环验证，显著标注非 AI；模式二为真实模型与隔离夹具，用专用评估模型配置，付费确认和调用预算为硬门禁。结果注明没有验证生产 Cookie/BFF/业务数据库/浏览器全链路。
- 内置赛事素材分页、当前版本记忆、自由探索三种场景。真实模型决定动作；夹具事实通过正常工具/记忆链进入 Agent，验收标准只供评分器。硬性证据不通过时不能用语义评分抵消。语义评委单独计调用，失败/缺证据为待复核或评分失败，不默认通过。
- 实验记录、逐次结果、取消/中断保存在独立评估 SQLite；每次试验使用新的隔离 CloudRepository，测试数据不进生产 cloud_*。服务单实例租约，重启将遗留任务标为 interrupted，绝不自动重放收费请求。
- 首版执行进度使用低频管理接口查询，与正常聊天 WebSocket 无关。关闭页面不取消实验；用户显式取消才停止后续执行。正文、工具证据按限长展示，不输出密钥、生产日志或隐藏推理。

## 交付边界

本轮实现源码与回归用例，不执行真实收费评测、部署或生产迁移。Windows/项目 Docker 规则继续生效。后续生产全链测试适配、自动用户模拟、写业务/生成产物 oracle、线上数据脱敏导入分别交付，不能把隔离夹具分数宣传为全平台生产成功率。
