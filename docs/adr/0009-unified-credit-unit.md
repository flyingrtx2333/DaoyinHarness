# ADR-0009：使用主平台统一积分单位

日期：2026-09-06。状态：已接受。

用户确认「积分」作为全平台 AI / 插件消费单位，1 元＝100 积分，保持价格与余额价值。主平台提供 `billing_unit` 元数据与十进制字符串 `*_credits` 金额，精度 6 位；财务成本和实际付款仍以人民币记录。

Harness 不维护独立汇率、钱包或收费倍率。付款账户、空间授权、余额预检、冻结、结算和退款仍由主平台及业务服务负责。后续付费插件接入必须使用其报价与结算接口，不能由模型或工具参数指定扣费金额。

同一计量单位不代表合并账户：Story 预付余额、Builder 授信与官网平台赞助账户保持各自归属。公开官网访客没有个人钱包，不展示个人积分余额；待接入插件不因使用统一单位而具备执行或扣费权限。

本次主平台提供积分单位与兼容字段，既有 CNY 账本与扣费事务保留。Harness 统一钱包、付费工具执行、跨应用余额池仍需独立交付；本 ADR 不宣称这些能力已接通。
