# ADR-0007：官网入口接入主平台授权与共享 Agent

日期：2026-09-05。状态：接受，后续实现由 [ADR-0008](0008-platform-public-bridge.md) 承接。主平台授权、检索/模型接口和会话代理现已实现；Windows 验证见 [统一平台说明](../UNIFIED-AGENT.md)。未部署。

## 目标决策

- 官网是第一个实际业务适配器，不将原 Python 公司问答循环包装成另一个 Agent 工具。共享 AgentEngine 调用主平台的公开知识检索工具和 company-assistant/chat 模型场景。
- 匿名访客使用独立 public 空间；不伪装成企业员工或个人注册用户，不读取个人/企业记忆。浏览器仅持有 HttpOnly、Secure、SameSite 访客 Cookie 和不具备授权能力的会话/请求编号。
- 主平台签发短期、可撤销、数据库存储摘要的委托令牌。Harness 只经服务端 introspection 获取身份；委托令牌只在适配器私有内存和 HTTP 认证头使用，不写入上下文、事件或工具参数。
- 主平台明确配置承担官网费用的租户和成员，验证有效成员关系。不存在默认 tenant=1 或首个租户选择。公开工具权限始终限定为 company.knowledge.read，不继承付款成员的管理权限。
- 原公开知识检索的分段、向量/关键词召回、重排、资料安全过滤复用；ContextVar 将相关模型用量归到本轮官网授权和付款方，不污染并发旧链路。
- 新旧官网链路必须显式选择。当前实现由 `AGENT_PUBLIC_ENABLED` 控制独立的新会话 API，旧 chat 保留，尚未自动切换界面。新链路失败不重跑旧 Agent；已带云端会话编号的请求不得退回旧模型执行。
- 模型和检索请求通过主平台持久化操作键去重；未知状态不重新收费执行。全站、访客和单 Run 设有调用次数上限，次数门禁不等同于人民币钱包冻结。
- 官网继续用既有 NDJSON UI 协议，新增 receipt、event_id 和显式 done。断线只重连同一个 session/request，服务端查询原 Run；停止按钮显式取消，不把浏览器断流冒充后端任务取消。

## 边界

本轮不开放短剧付费写入、不迁移 Builder、不接入企业私有资料，也不宣称已经完成个人/组织应用授权产品。SQL 迁移由 Windows/部署环境显式运行；未部署、不自动更改生产配置。SQLite 云端仍是单实例试运行适配，公开上线前必须完成隔离测试、代理限流、数据库备份和部署验收。
