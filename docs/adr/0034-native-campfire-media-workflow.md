# ADR-0034：Harness 内置营火实拍剪辑能力

状态：接受；2026-10-09，替代 ADR-0032 的工作台接入方向。

## 决定

营火成为 Harness 自有的素材与短视频剪辑能力。工作台不再调用营火业务服务、MCP、连接表或营火账号。当前道引账号和空间决定资源归属，素材、分析、剪辑计划及结果由 Harness 持有；模型继续通过认证 AI Gateway 调用，供应商凭据仍由主平台持有。

素材库保存店铺文字资料、实拍图片、实拍视频和参考视频。聊天框「＋ → 营火」选择店铺及参考视频，也可以就地上传。选择只是表达本次创作意图，不是插件授权。

第一版优先重剪店铺真实素材。参考视频仅用于分析镜头、节奏及结构，不能作为本店商品、价格、地址、人物或卖点的证据，不能直接拼入成片。缺镜头必须先说明并询问是否用 AI 补充；不能因缺素材自动付费生成。本阶段不实现或宣称 AI 补镜头成功。

## 实现边界

复用 Harness 通用资源服务、账号/空间隔离、内容寻址存储、不可变资源事件及 gVisor 执行器。原始上传、分析和剪辑计划拥有独立资源 ID；新输出是新资源，失败或取消不覆盖原素材和之前的成片。资源事件是素材清单的可重建事实来源。

媒体处理运行于固定 FFmpeg 媒体镜像，接受结构化参数，不接受用户拼接的命令。上传分块、受大小限制并在提交时核验完整性；未完成的上传不进入可选素材。素材读取和每次工具执行都重新核验当前账号/空间。

模型使用实际媒体元数据与抽样画面制定有界的剪辑计划；服务端验证每个片段的真实素材归属、时间范围和参考片隔离。计划记录缺失镜头，存在缺失项时禁止渲染。先产出可预览的 MP4，修改生成新计划/成片，不覆盖历史版本。不把任务受理、文件存在或进程退出误报为视觉质检通过。

主平台仅同步 Harness 自有工具契约并转发经过账号、Origin 和 CSRF 校验的请求，承担模型调用和记账。不得建立第二套店铺账号或将原营火数据库迁入 Harness。

## 验证

遵循 docs/TESTING.md，只运行小样本真实模型和真实工具路径。空素材、参考视频隔离、实际素材剪辑分别记录；缺真实店铺资料时不虚构店铺事实。静态检查与打包不作为 Agent 行为证明。
