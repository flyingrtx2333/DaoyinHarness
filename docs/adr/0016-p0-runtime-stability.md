# ADR-0016：P0 流式稳态、上下文与运行诊断

2026-09-06。范围：源码与回归用例；生产发布、备份恢复演练和真实付费验收另行执行。

## 已知基线

`deployment/RELEASE-20260906-WS-POSTGRES.md` 已记录 WebSocket/PostgreSQL 联合上线：Harness `efe56eb9926d200fa952145b483b61e629c51b25`，主平台及官网 `11f750738b5415b8d0f10c2307b337fe65e09fd1`。这是已有发布记录，不是本次对服务器的独立复验。本轮不再次导入 SQLite。

## 决策

1. 在 AgentEngine 的公开正文回调与持久事件之间增加有界缓冲。首段尽快写入，后续按 100ms 或 2KiB 合并，不跨 contentBlockId；工具派发及成功终态前必须排空。取消、超时、记忆失效、异常时丢弃尚未保存的缓冲，并等待已开始的保存结束，禁止终态后追加。已落库事件仍不可变。计时器异常必须向执行链传播，不后台吞错。
2. 不再用 1,000 条原始事件作为主要会话限制。新增统一的回合/字节/事件上限与有界完整历史读取；达到读取上限明确失败，不能静默返回前 1,200 条并误判最新回合。HTTP 回放同时按条数及字节分页，hasMore 必须覆盖字节截断。
3. 系统提示词只拼一次。新请求保留结构化稳定/动态字段，去掉完全相同的 system 镜像；主平台兼容旧重复请求。只能按完整、规范化等价内容去重，不用子串删掉独立指令，更不修改用户、工具或助手正文。
4. 增加不调用收费模型的存活、就绪与版本信息。就绪检查核对数据库、所需 schema、执行租约和平台可达性；读探针不冒充写入实测。版本元数据来自构建产物，不在运行时把当前 Git HEAD 当成线上版本。未配置的检查返回未就绪，不默认成功。
5. 增加受原会话权限保护的 Run 诊断，优先从持久事件派生首段、工具和总体时序，并补充内存中的数值化阶段耗时。不给模型或访客全平台监控权限，不记录提示正文、工具参数、供应商密钥或隐藏推理。重启后不存在的观测明确标记 unavailable，不能填假值。

## 验收

首段实时可见；碎片合并后字节不超界、文本不丢不重；异常/取消无迟到写入；超过旧 1,200 条仍能读取最新终态；字节分页不断页；新旧提示协议只拼一次；健康探针不创建 Run、不收费、不泄露连接信息；诊断跨账号/空间拒绝。使用本仓规定的 Windows 环境与主平台项目 Docker 进行验证，记录 fresh 结果，不复用历史测试数。
