# ADR-0035：内置营火完整制作链路

状态：实施中；2026-10-09。

## 目标与证据

东北荟真实素材验证已完成上传、分析、计划和 MP4 重剪，但输出只有固定三秒切镜、黑边和字幕，缺少原营火成片的口播、背景音乐、模糊背景及精细节奏。这不满足完整制作效果要求。继续使用 Harness 自有资源、账号和制作记录，不调用或复用原营火制作实现。

完成条件逐项验证，不能用文件存在或一次技术样片替代：

1. 店铺资料、图片、视频、参考、配音和音乐属于当前账号/空间；上传、查询、预览、更新资料和分页可实际使用。
2. 参考分析提供真实切点、时间窗口画面与叙事依据，模型根据参考安排可变镜头长度；实际素材不足时询问，授权后才可补充 AI 镜头，且明确标记来源。
3. 配音通过主平台已认证、已计费的 AI Gateway，保留真实音频时长与可用时间戳；字幕、镜头和口播共同组成有界时间轴。供应商凭据不进入 Harness、浏览器或事件。
4. 使用明确来源和许可的音乐或用户提供的音轨，旁白优先混音、淡入淡出和响度处理；参考音轨不自动挪用。
5. 默认输出 1080p/30fps，横屏实拍竖屏使用模糊背景，支持主体裁切和明确选择的黑边适配。字幕可读、无溢出、文字与当前画面/口播一致。
6. 制作有可查询阶段、取消与失败原因。修改产生新计划、新成片；原素材和上一次成功版本不覆盖。重复请求不重复付费；处理中或结果不明时先查询。
7. 对话和素材库能预览、下载、选参考及继续修改。小样本真实模型完成东北荟制作、修改、缺镜头询问，并与原成片逐项对比；不能把原成片当生成输入。

## 所有权与接口

Harness 资源服务持有媒体、不可变计划、音轨、分析与输出。FFmpeg 仍在无网络 gVisor 媒体工作区接受结构化参数。模型不提供命令、文件路径或任意远程地址。

计划支持逐镜头的时间范围、字幕、适配方式及裁切焦点，独立的旁白/音乐资源与音量。旧计划继续按旧字段读取，补充默认值只作用于新计划或渲染，不改写历史事件。音轨上传适用同账号、格式核验和大小限制。

付费配音与 AI 补镜头通过主平台现有模型凭据、账号权益和用量记账提供专门的媒体 Gateway；Harness 保存请求 ID、阶段和结果，不接受供应商密钥。主平台接口同步属于必要的协调改动，不把旧营火连接或旧营火数据库引入新流程。尚未提供的 Gateway 不可展示为已经完成。

## 当前进度与验证边界

### AI 补镜头执行合同

补镜头先关联已保存计划中某一条实际 `missingShots`，保存不可变的提示词、规格与主平台报价。模型可准备报价，但不能替用户确认。浏览器的明确制作确认通过 browser-only 操作记录到该报价资源；这属于具体付费制作请求的确认，不是插件授权或额外权限授予。确认过期或价格变化时重新报价，不把模型返回的 `approved: true` 当作用户授权。

已确认报价对应一个稳定的主平台视频请求，提交、查询和下载都按当前账号隔离。同一报价不再提交第二个供应商任务；处理中或提交结果不明时查询原请求。首版使用主平台已配置的文字生成视频能力生成明确的演绎画面，不伪称还原本店现场，也不自动搬用参考人物、商标或店铺事实。主平台持有凭据、计费记录和转存结果；Harness 只接收该请求受控下载的实际 MP4 字节。

完成素材记录 `generated: true`、报价/计划关联、模型和供应商来源。素材库展示“AI 演绎”，所有使用该素材的成片在对应镜头叠加该标记。补充后重新 inspect，并保存新的完整剪辑计划；原缺失计划、实拍素材及历史成片不改写。取消聊天停止后续工具工作，不冒充已撤销供应商已接受的付费任务，原任务仍可查询和收取结果。

本 ADR 是实施与验收合同，不是完成证明。代码、真实模型验证、提交推送、生产部署分别记录。仅运行 docs/TESTING.md 允许的小样本真实链路，静态检查不证明模型行为。
