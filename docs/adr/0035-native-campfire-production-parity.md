# ADR-0035：内置营火完整制作链路

状态：实施中；2026-10-09。

## 目标与证据

东北荟真实素材验证已完成上传、分析、计划和 MP4 重剪，但输出只有固定三秒切镜、黑边和字幕，缺少原营火成片的口播、背景音乐、模糊背景及精细节奏。这不满足完整制作效果要求。继续使用 Harness 自有资源、账号和制作记录，不调用或复用原营火制作实现。

完成条件逐项验证，不能用文件存在或一次技术样片替代：

1. 店铺资料、图片、视频、参考、配音和音乐属于当前账号/空间；上传、查询、预览、更新资料和分页可实际使用。
2. 参考分析提供真实切点、时间窗口画面与叙事依据，模型根据参考安排可变镜头长度；实际素材不足时调整现有素材方案或等待上传实拍，不生成补充画面。
3. 复用已有配音素材，保留真实音频时长与可用时间戳；字幕、镜头和口播共同组成有界时间轴。供应商凭据不进入 Harness、浏览器或事件。
4. 使用明确来源和许可的音乐或用户提供的音轨，旁白优先混音、淡入淡出和响度处理；参考音轨不自动挪用。
5. 默认输出 1080p/30fps，横屏实拍竖屏使用模糊背景，支持主体裁切和明确选择的黑边适配。字幕可读、无溢出、文字与当前画面/口播一致。
6. 制作有可查询阶段、取消与失败原因。修改产生新计划、新成片；原素材和上一次成功版本不覆盖。重复请求不重复付费；处理中或结果不明时先查询。
7. 对话和素材库能预览、下载、选参考及继续修改。小样本真实模型完成东北荟制作、修改、缺镜头处理，并与原成片逐项对比；不能把原成片当生成输入。

## 所有权与接口

Harness 资源服务持有媒体、不可变计划、音轨、分析与输出。FFmpeg 仍在无网络 gVisor 媒体工作区接受结构化参数。模型不提供命令、文件路径或任意远程地址。

计划支持逐镜头的时间范围、字幕、适配方式及裁切焦点，独立的旁白/音乐资源与音量。旧计划继续按旧字段读取，补充默认值只作用于新计划或渲染，不改写历史事件。音轨上传适用同账号、格式核验和大小限制。

当前只处理已有媒体，不调用配音或视频生成 Gateway，不把旧营火连接或旧营火数据库引入新流程。

## 当前进度与验证边界

### 2026-10-09：仅已有素材剪辑

用户明确要求“只用素材”“改代码逻辑，只用素材剪辑”，取代本 ADR 早先的 AI 补镜头方案。当前能力不再注册或执行补镜头报价、确认、提交、查询导入及新旁白生成工具；资源服务拒绝旧客户端的这些操作，且不再连接媒体生成 Gateway。历史事件、音轨和成片保留，历史报价卡仅展示停用说明，不能恢复生成。

制作计划和渲染均拒绝带 AI 来源或生成标记的店铺画面。可使用已有店铺图片、视频及已有旁白、音乐音轨，内置许可音乐仍属于可选素材。参考视频仅分析节奏，不拼入输出。素材不足时调整现有素材方案或等待上传实拍，不询问 AI 补充、不报价、不生成。既有音轨的真实字幕时间轴仍可复用，不生成新的音轨。

本 ADR 是实施与验收合同，不是完成证明。代码、真实模型验证、提交推送、生产部署分别记录。仅运行 docs/TESTING.md 允许的小样本真实链路，静态检查不证明模型行为。

### 旁白优先的现场声混音

使用已有旁白时，现场声和配乐分别由旁白控制自动压低，旁白停顿或结束后释放压低，保留实拍氛围。`sourceVolume` 是压低前的现场声音量，`musicVolume` 是压低前的配乐音量；没有旁白时不启用这项控制。旁白响度处理后统一回到48kHz，再分发给两条控制音轨，避免响度滤镜改变采样率影响混音时间轴。无配乐时只保留旁白和现场声两条音轨。该处理不分离或删除原实拍中的人声，不能保证所有嘈杂素材均能获得相同的听感。

## 已登录媒体分段读取

成片播放器直接使用同源 BFF 媒体接口，不先将完整文件转为浏览器 Blob。BFF 仍用当前账号 Cookie 解析身份并获取既有服务端执行身份；地址只含真实资源 ID 和非秘密的账号范围摘要，摘要只校验旧播放器是否属于当前账号，不能授权或更改身份，地址不含 bearer、登录凭据或供应商链接。当前工作台应用为 saishi。

云端接口 `/api/v1/cloud/resources/media/:resourceId` 复用 `resource_media_read` 权限与资源所有权检查，提供 GET/HEAD、单段 Range、206/416。JSON 素材读接口保留。媒体类型、总大小、逐块字节范围均核验，不把平台或模型返回的远程地址转交浏览器。服务端逐块传输、消费背压、断开停止后续读取，最长流120秒；不冻结积分或生成新媒体。播放和下载保持 no-store、nosniff，不为文件创建公开授权链接。

### 2026-10-10 默认自动制作与旁白授权

用户明确要求无需逐项确认、自动生成旁白并选择配音、默认竖屏。这项新要求取代此前将“只用素材”扩展成禁止新旁白的限制；“只用素材”继续约束画面，不恢复任何 AI 补镜头或报价工具。制作请求默认 9:16、1080p/30fps，依据已确认店铺事实和实拍画面自动写旁白，通过已有主平台账号配音网关生成女声普通话（可按内容选男声）并真实测量字幕时间轴，自动选择内置许可配乐、保存计划并渲染。缺少地址、价格、营业时间等非必要信息时省略，不编造、不为这些可省略信息停止制作。只读或先看方案的请求不触发付费配音。保留原请求键、音频事件与状态查询，失败不重复提交付费配音。
