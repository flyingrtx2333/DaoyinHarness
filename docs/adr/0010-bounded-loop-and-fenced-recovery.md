# ADR-0010：有界工具循环、完整上下文与受控恢复

日期：2026-09-06。状态：已提交并部署。Windows 全仓 293 项测试及构建通过，生产租约、历史保留、真实公开检索问答、去重、回放与取消已验证。实现范围见 [内核可靠性改造](../ENGINE-RELIABILITY.md)，生产证据见 [上线记录](../../deployment/RELEASE-20260906-ACCOUNT-ACCESS.md)。

## 问题

原内核只按调用 ID 去重，畸形批次可能在部分工具已经执行后才被发现；取消后迟到的模型响应可能仍被记录为成功。历史正文与执行证据分开装配，而自定义系统提示词绕过了默认的压缩/恢复区块。单条工具结果有限长，但单轮累积工具消息没有总预算。云端重启留下的 running 状态只能人工处理，也缺少同一数据库的执行所有权门禁。

## 决策

1. 先验证整批模型工具调用再执行。无效结构、重复调用 ID、过大参数不能进入下游模型协议；不重试结果不确定的模型调用。
2. 增加回合内进展门禁：规范化参数指纹，不把换调用 ID 视为进展；默认阻止没有其他写操作介入的重复写，轮询类只读调用允许有限次相同结果。确需重复的工具由可信工具定义显式声明，不由模型参数开放。
3. 取消在模型调用前后和批次各工具之间检查；保留已执行工具的事实，不把完成部分工具解释成整个回合成功。相同已完成回合重入直接读终态；已有非终态回合拒绝盲重放。
4. 会话证据、压缩摘要和中断警告由上下文装配器补齐，自定义 Profile 不能无意丢弃它们。压缩只覆盖完整、连续的已结束回合，摘要保持合法结构，不能硬切 JSON 或跨越未结束回合。
5. 对模型请求设置总字符和消息数量预算。保留本轮用户目标和最新完整工具调用/结果组；较早工具组转为带来源的有界检查点，历史消息按完整回合裁剪。不修改原始事件，不将截断误称为资料不存在。
6. 云端增加 SQLite 单实例运行租约和写入隔离。标准启动入口获得租约后只把旧任务标记 interrupted，不自动重放模型或外部操作；旧实例失去租约后不能追加结果，并停止接受执行。首次从无租约旧版本升级必须先停止旧服务。

## 边界

本轮不接短剧/文旅业务，不迁移用户数据，不实现跨机器分布式任务系统，不自动恢复结果不确定的付费操作。SQLite 租约不是对外部供应商的事务或撤销保证。用户可在新回合根据保留的事实继续任务；原请求 ID 始终对应原执行。

## 验证

新增回放模型与临时存储测试，覆盖整批校验、换 ID 重复、变化中的轮询、取消迟到、终态复用、长上下文、压缩边界和租约交接。仅 Windows PowerShell 允许执行依赖/类型/测试/构建；不以旧验收记录代替本轮结果。
