# ADR-0011：版本化长期记忆与受控共享

日期：2026-09-06。状态：实施中，未部署；本轮仅修改 Harness。

后续规则更新：下文逐应用共享授权描述的是当前实现，已由 [ADR-0012](0012-first-party-account-access.md) 的产品决策取代。同账号、同空间内已有权限的数据与记忆须自动供已接入插件使用，无需逐条授权到目标插件；记忆接入实现仍需按此调整。记录版本、候选确认、来源追踪、账号/企业隔离与忘记语义继续保留，不能将内容生命周期操作作为插件访问授权关卡。

## 决策

- 会话事件、压缩摘要、知识库与长期记忆是不同对象。保留本地 JSONL 记忆，不自动上传或归入企业。
- 增加云端持久记忆仓储和共享内核的记忆读取接口。作用域由认证身份确定，不接受模型指定用户或租户。公开访客不读取或保存私人长期记忆。
- 本阶段提供应用内个人记录、个人通用记录、企业共享记录三种长期范围。会话历史继续由事件库负责；资源级记忆需业务资源 ACL 适配后另行开放。
- 新记录先为 pending，用户管理 API 确认后才 active。更正创建候选版本，确认前旧记录仍生效；确认时校验旧版本，避免并发覆盖。模型没有确认、共享或删除的工具权限。
- 跨应用共享逐条授权到目标应用实例，授权绑定记录版本和有效期。目标应用必须经过平台检查；默认不支持个人到企业、企业到个人或跨企业共享。撤销和更正不自动把新版本扩散给旧授权。
- 先按用户、空间、应用和共享授权筛选，再做中文/英文关键词排序。只召回少量相关条目，保存来源、版本、召回理由和每步引用记录。关键词排序不是语义向量检索。
- 每次模型调用重新检索并核对引用，回复或工具分派前再次检查；撤销或更正发生在调用期间时，停止使用该回答，不自动再请求收费模型。
- 记忆正文不复制进新的工具结果或事件。对引用已失效记忆的历史回合，在模型上下文投影中隔离，不改写原事件。具有长期记忆读取器的回合暂不复用缺少记忆依赖的旧压缩摘要，以免失效正文从摘要复活；仍使用总上下文预算。
- 忘记会清空本仓储该记忆链的正文并撤销授权，保留无正文审计记录。已经展示的回答、原始用户消息、旧本地 JSONL 与备份不属于自动物理擦除范围，不能声称全盘遗忘。

## 验证范围

新增纯策略、临时 SQLite、模拟身份/模型的回归测试。检查未确认记录不召回、跨用户/企业隔离、共享撤销、冲突更正、过期、幂等、模型调用中撤销和历史隔离。本连接为 WSL，仅进行源码和文档编辑，不运行 Windows 专属构建或测试。真实主平台权限签发、管理界面与上线另行验收。
