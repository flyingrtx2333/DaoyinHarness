# ADR-0006：共享 Agent 内核与隔离的云端运行适配

- 日期：2026-09-05
- 状态：接受；第一阶段已进入 Windows 验证，最新范围与结果见 [统一平台说明](../UNIFIED-AGENT.md)

## 背景

道引的短剧、文旅、企业工作台、官网问答与未来自建产品需要复用同一 Agent 内核。现有 Harness 的 loop、事件和工具接口可以复用，但本地文件存储、单账号生命周期和工具测试默认身份不能作为云端租户隔离。

本决策扩展 ADR-0002 的运行部署范围，不放宽本地端的 loopback、凭据和工作区限制。现有本地产品继续保留；不合并业务数据库、不迁移用户历史、不部署主平台。

## 决策

1. 新增 `@daoyin/harness-contracts`，承载与环境无关的事件/压缩存储接口、执行身份和记忆作用域契约。本地 workspace 继续兼容导出旧存储类型。
2. `AgentEngine` 仍是唯一通用执行循环。本地调用兼容原有输入；云端必须提供由认证适配器解析的执行身份，不能由请求正文、模型工具参数或默认租户生成身份。
3. 会话固定绑定操作者、个人/组织空间、应用安装实例。付款账户与授权 ID 属于每次执行的授权上下文，不混同数据所有者。授权过期或撤销时必须停止新的模型/工具工作。
4. 工具注册表支持异步授权：发现时过滤，执行时再次校验。移除省略上下文时的 `local_test` 等测试身份。无身份、策略异常、过期或拒绝均失败关闭。
5. 新增独立 `server-cloud` 服务工厂，使用同一个 AgentEngine。首版只允许显式注册的只读业务工具，不挂载文件系统、进程、浏览器、MCP 万能调用或长期记忆写入。
6. 云端会话/请求/事件由 `CloudRepository` 管理；第一阶段提供真实 SQLite 单实例试运行适配，使用原子事务、请求幂等和不可变事件。它不是生产多 Worker MySQL 实现；没有自动故障接管，也不能用进程内任务表声称具备分布式调度。
7. 首版认证与模型接入是必填的服务端适配器，不提供开发 token 或超级管理员兜底，不猜测主平台尚不存在的接口。模型适配器负责把已确认的付款授权交给网关；本阶段没有实现余额预留和付费业务操作。
8. HTTP 层提供创建/查询会话、提交/查询 Run、事件游标回放和取消。请求先持久化后接受；相同幂等键及正文返回同一 Run，正文改变返回冲突。异常重启遗留任务标记 interrupted，不自动重放未知外部副作用。
9. 跨应用记忆目前仅明确作用域与授权契约，不开启历史自动合并或同步。业务服务仍是资源和任务状态的事实源。

## 不在本轮范围

主平台 OAuth 多空间选择改造、真实官网/Story API 适配、云端前端、企业成员管理、MySQL 多 Worker 租约调度、自动恢复付费工作流、统一账务、跨业务记忆迁移以及 Builder 运行时迁移。

## 验证要求

增加身份、工具授权、跨用户/空间/应用隔离、请求幂等、断线事件回放、持久化重开和中断处理测试。模型与认证使用明确标注的测试替身；SQLite 测试使用临时数据库。共享 checkout 仅在 Windows PowerShell 安装依赖、运行 typecheck/lint/test/build；WSL 不运行这些命令。
