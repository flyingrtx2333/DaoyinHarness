# ADR-0039: 公有读 WebP 缩略图

状态：已采纳（2026-10-10，用户明确要求公开缩略图）

覆盖 ADR-0037 的 COS 缓存访问级别，原始资源、视频、店铺资料和成片仍使用原有鉴权。只有已校验的派生 WebP 封面使用 `public-read`，匿名持有对象地址者可以查看封面。

公开缓存使用独立前缀 `harness/thumbnails/v2/`，不批量修改旧 `v1` 对象或整个桶。既有素材再次请求封面时，复用已生成的原生 WebP，在新前缀写入公有读、私有写对象；不重复生成、剪辑或调用模型。BFF 继续验证账号与资源归属、WebP 格式、大小和 SHA-256 摘要，并在 COS 不可用时返回原生封面。

主平台只调整 `services/harness_thumbnail.py`。不修改通用 COS 上传函数、桶策略、其他素材 ACL 或业务数据。宽泛的匿名上传/删除桶策略仍需桶管理员单独撤销；对象的 `public-read` 设置不是对该策略的收窄。

验收使用实际素材和 COS：匿名 GET 返回 WebP 且摘要一致，应用缓存路径返回 `cos`。静态检查与真实媒体验证分开记录，无模拟测试或付费生成。
