# ADR-0019：评估使用真实账号链路并独立发布

日期：2026-09-07。状态：已实施并上线；已完成两条真实小样本链路验收，业务语义判定仍待复核。见 `deployment/RELEASE-20260907-EVALUATION-LIVE.md`。

## 背景

评估页面和主平台转发已发布，但独立 systemd 服务、版本链接与 Nginx 路由缺失。旧执行器的 live 模式仍使用模拟业务返回和内存会话，replay 则预设回复；它们不符合所有者要求的小样本真实模型规则，不能通过启动旧执行器宣称系统已完成验收。

## 决策

独立评估服务只接受真实模式，每批最多五次试验，默认每题一次。沿用平台超级管理员、有效第一方账号、当前租户与业务授权，不复制供应商密钥。评估服务通过有严格操作白名单的主平台内部接口调用实际云端 session/run/events；真实模型经现有网关计费，业务工具访问当前账号已有权限内的真实资源。单轮模型调用上限只能降低至 2–12 次，不增加生产默认权限；每次试验先保留预算，提交编号和云端会话/任务 ID 留证，取消和超时停止已受理任务，不自动重提不确定的写请求。

结果记录真实状态、回复、工具、模型调用尝试及可用时延。未接通独立事实核对和判分前，业务正确性标记待复核；没有真值集合时召回率为未测，不通过非空回答或模型自评虚构通过率。明确区分完成率与验证成功率。旧模拟代码和历史记录仅保留溯源，不作为服务执行入口。

评估进程使用独立低权限 OS 用户、环境文件与 SQLite 报告库；实际会话沿用云端 PostgreSQL，不对原有会话做迁移或清空。Nginx runner 转发保持服务凭据和每次管理员复查。发布先备份并校验服务与配置，评估、云端、工作台分别核验，故障回滚不得丢失业务数据。
