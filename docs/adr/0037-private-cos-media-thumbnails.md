# ADR-0037: 私有 COS WebP 素材封面

状态：已采纳（2026-10-09）

素材库卡片不加载原图或原视频。原始资源继续使用不可变内容存储；封面是可重建的派生缓存，不替代原始上传、检查证据或成片。

`resource_media_read` 的浏览器操作新增 `thumbnail: true`，要求 `offset: 0`。资源服务先验证资源所有权，再在现有无网络 gVisor 媒体环境中抽取首帧，生成保持比例、最长边不超过480px、质量35的 WebP，最多96KiB。每资源串行生成，进程内最多两个任务；在获取数据库锁前排队。成功后追加 `campfire.thumbnail.ready`，记录源摘要和封面摘要，旧资源无需迁移即可按需生成。缓存写入属于只读素材操作的派生索引维护，不修改原始素材清单。

同源媒体 BFF 的 `thumbnail=1` 分支复用当前账号 Cookie、空间检查和原有资源读取授权，每次先调用资源服务验证所有权。主平台复用已有 COS 连接，将封面写入私有对象：`harness/thumbnails/v1/<accountScope>/<resourceId>/<digest>.webp`。对象显式使用 `ACL=private`；COS 凭据、对象地址和签名链接不进入浏览器、会话或工具回执。返回字节验证摘要，响应标注 `X-Harness-Thumbnail-Storage: cos`；COS 不可用时返回原生封面并标注 `native-fallback`，不回退下载原视频。

素材网格仅使用懒加载 `<img>` 展示 WebP，保留横竖比例。点击预览、播放和下载继续使用原媒体的鉴权 Range 流。下载参数优先于缩略图参数，避免低质量封面被当作原文件下载。

验证使用真实账号、真实素材和实际 COS；静态检查、资源路径/UI 验证与真实模型验证分别记录。此变更不增加模型调用、AI补镜头或业务授权步骤。
