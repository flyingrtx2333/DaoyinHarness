# 营火：Harness 内置实拍剪辑

2026-10-09 的产品方向：不再连接原营火账号、MCP 或业务服务。使用已登录的道引账号，在 Harness 中保存资料、素材和制作记录。决策见 [ADR-0034](adr/0034-native-campfire-media-workflow.md)。

## 使用

1. 在「资产 → 素材库 → 上传素材」添加店铺名称和真实资料。
2. 选择店铺，上传实拍图片、MP4 视频或 TXT/Markdown 店铺文档。参考视频使用单独的「参考视频」用途，不能作为本店实拍。
3. 在聊天框「＋ → 营火能力」选择店铺和素材库里的参考视频，也可直接上传参考 MP4。选定后输入制作要求；选定营火时「＋」中的图片/视频会直接存到当前店铺的 Harness 素材库。
4. Agent 查询真实素材、读取实际时长和抽样画面、保存剪辑计划并重剪。成功的成片出现在当前对话与素材库，可预览和下载；修改保存为新计划及新成片。

参考视频仅用于镜头、节奏、画幅和文案结构。其商品、人物、价格、地址及卖点不能当作本店事实。缺镜头时调整现有素材方案，或等待上传新的实拍素材；不询问 AI 补充、不报价、不生成新画面、旁白或音乐。素材已有音轨可保留；无音轨的片段保持静音。完整制作目标与逐项验收见 [ADR-0035](adr/0035-native-campfire-production-parity.md)。

## 当前剪辑功能（实际样本单独验收）

- 新计划支持最多48个镜头、180秒；根据参考的实际切点和指定时间窗口查看画面后安排可变长度，不默认平均3秒。模型每次响应最多3个工具调用，分批分析素材。
- 默认1080p/30fps，横屏素材使用模糊背景；`framing=crop`按`cropX/cropY`（0–1）裁切主体，`contain`为用户明确选择的黑边。图片和视频均可使用 `motion=push-in`，在当前镜头内从原画面平滑推近至1.08倍；`motion=none`保留固定适配。
- 中文字幕按实际画幅分行，每页最多两行；长字幕分时显示，过滤可被解释为字幕控制指令的字符。
- 可上传本店MP3/WAV/M4A旁白或音乐，实际inspect音轨后使用`audio.narrationId/musicId`。旁白不能长于计划；音乐循环、淡入淡出、旁白时压低配乐、整体响度处理。仅复用已有音轨和实际字幕时间轴。内置CC0许可City Sunshine属于可选音乐素材，来源和文件校验见[许可记录](../packages/server-cloud/src/resources/music/PROVENANCE.md)。历史旁白、音乐和成片保留；当前不注册或执行新音轨生成及AI补镜头工具。
- 渲染逐镜头记录`campfire.render.progress`和混音阶段；新输出记录分辨率、帧率和音轨资源。既有计划和成功输出仍保留。
- 图片和视频通过同源账号媒体接口直接预览；视频支持HEAD和单段Range，不先下载完整Blob。逐块验证大小、类型、字节范围和账号，断开后停止后续读取。

## 第一版边界

- 单文件最多 128 MiB；图片支持 JPG/PNG/WebP，视频支持 MP4，文档支持 40 KiB 内 TXT/Markdown。视频解析时长最多 1 小时。
- 新计划最多48个片段、180秒成片，支持9:16、16:9、1:1和字幕。旧计划及旧成片保留原有参数和历史记录。不会直接拼入参考视频。
- 素材库首批最多100项，使用“加载更多素材”继续读取；“店铺素材 / 已生成内容”分别展示已有素材与剪辑成片，支持横竖混排、图片/视频筛选、已加载标题搜索和列表视图。店铺与参考选择器独立按用途分页，不受最新素材数量影响；上传未完成的资源不进入素材选择。API每页1至100项，返回hasMore和nextCursor；用pageCursor继续读取时保留shopId/filterRole筛选。分页按不可变创建时间和ID定位，没有1000项总量上限。
- 店铺资料可在素材库修改；resource_media_profile更新携带resourceId和expectedVersion，追加新版本而不重写旧资料，过期版本返回冲突。重复同一次成功更新返回原结果。新计划保存当时的shopProfile事实和版本，资料以后更新不改变已保存计划。
- 使用固定 FFmpeg/中文字体镜像和 gVisor、无网络媒体工作区。模型通过道引 AI Gateway 读取压缩抽样画面，未抽样的内容不应被声称已经逐帧核对。
- 视频抽样时间来自实际解码帧，按从左到右、从上到下排列。参考视频在候选区间足够时优先选择分布于窗口的六个镜头中点，避开切换边缘；否则使用等距目标。画面变化切点是启发式候选，不是完整语义分镜。六张图不能覆盖全部镜头，细节须指定时间窗口继续查看。新分析以版本3追加，旧分析和事件保留。
- 各账号/空间拥有独立资料、素材、计划和结果。内置媒体能力继承有效道引账号访问，不扩大通用代码执行的现有准入范围。
- 原素材、计划、分析和结果事件不可变。上传重试按块验证内容；同一计划的重复渲染返回原成片或原状态，不在失败后覆盖结果或隐式重跑。

## 部署与验证

需要同步 Harness runtime/UI、资源服务及主平台的 Harness 工具契约与抽样画面转发逻辑。当前资源服务不连接媒体生成Gateway；主平台媒体转发仍执行账号所有权、原始字节长度、类型和范围校验。媒体镜像以明确 digest 配置在资源服务和执行器的 `HARNESS_RUNTIME_IMAGES.media`；保留其他运行环境配置。主平台设置 `AGENT_YINGHUO_ENABLED=0`，防止旧远程工具进入工作台。原营火服务和数据库无需修改或迁移。

只进行小样本真实模型/真实上传/真实工具/持久化验证；静态检查和打包不等于 Agent 验收。生产验收结果单独记录精确 revision、实际环境、模型、输入、工具、保存结果与限制。

高清实拍完整制作的生产运行时限目前显式设置为`DAOYIN_CLOUD_RUN_TIMEOUT_MS=600000`（十分钟有界上限），单轮模型调用仍最多12次。默认五分钟曾实际中止东北荟渲染，不能把这个被取消的任务视为生成成功。禁止新配音不等于禁止用已有音轨渲染；失败/取消后先查原计划事实，不重跑已有render.started的计划。
