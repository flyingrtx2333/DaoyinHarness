# 营火：Harness 内置实拍剪辑

2026-10-09 的产品方向：不再连接原营火账号、MCP 或业务服务。使用已登录的道引账号，在 Harness 中保存资料、素材和制作记录。决策见 [ADR-0034](adr/0034-native-campfire-media-workflow.md)。

## 使用

1. 在「资产 → 营火素材」添加店铺名称和真实资料。
2. 选择店铺，上传实拍图片、MP4 视频或 TXT/Markdown 店铺文档。参考视频使用单独的「参考视频」用途，不能作为本店实拍。
3. 在聊天框「＋ → 营火能力」选择店铺和素材库里的参考视频，也可直接上传参考 MP4。选定后输入制作要求；选定营火时「＋」中的图片/视频会直接存到当前店铺的 Harness 素材库。
4. Agent 查询真实素材、读取实际时长和抽样画面、保存剪辑计划并重剪。成功的成片出现在当前对话与素材库，可预览和下载；修改保存为新计划及新成片。

参考视频仅用于镜头、节奏、画幅和文案结构。其商品、人物、价格、地址及卖点不能当作本店事实。缺镜头时先询问是否补充；当前尚未实现自动 AI 补镜头。逐句自动配音已接入主平台账号网关并部署；实际样本与费用记录单独验收。素材已有音轨可保留；无音轨的片段保持静音。完整制作目标与逐项验收见 [ADR-0035](adr/0035-native-campfire-production-parity.md)。

## 当前完整制作功能（已部署，实际样本单独验收）

- 新计划支持最多48个镜头、180秒；根据参考的实际切点和指定时间窗口查看画面后安排可变长度，不默认平均3秒。模型每次响应最多3个工具调用，分批分析素材。
- 默认1080p/30fps，横屏素材使用模糊背景；`framing=crop`按`cropX/cropY`（0–1）裁切主体，`contain`为用户明确选择的黑边。图片可使用轻微推近。
- 中文字幕按实际画幅分行，每页最多两行；长字幕分时显示，过滤可被解释为字幕控制指令的字符。
- 可上传本店MP3/WAV/M4A旁白或音乐，实际inspect音轨后使用`audio.narrationId/musicId`。旁白不能长于计划；音乐循环、淡入淡出、旁白时压低配乐、整体响度处理。narrate逐句通过主平台账号网关生成配音，实际测量音频长度和字幕时间；固定请求标识保留原结果，不隐式重新计费。music可选择内置CC0许可City Sunshine（独立从公开FreePD来源获取），来源和文件校验见[许可记录](../packages/server-cloud/src/resources/music/PROVENANCE.md)。配音按现有账号检查额度并记录真实用量；供应商计价未配置时必须标为待计价，不能声称已完成扣费。
- 渲染逐镜头记录`campfire.render.progress`和混音阶段；新输出记录分辨率、帧率和音轨资源。既有计划和成功输出仍保留。
- 预览使用最多4路并发读取不可变媒体块，每块验证大小、类型、结束位置与账号，保留取消检查。

## 第一版边界

- 单文件最多 128 MiB；图片支持 JPG/PNG/WebP，视频支持 MP4，文档支持 40 KiB 内 TXT/Markdown。视频解析时长最多 1 小时。
- 新计划最多48个片段、180秒成片，支持9:16、16:9、1:1和字幕。旧计划及旧成片保留原有参数和历史记录。不会直接拼入参考视频。
- 当前素材列表显示最近 100 项，明确标记尚有更多；上传未完成的资源不进入素材选择。
- 使用固定 FFmpeg/中文字体镜像和 gVisor、无网络媒体工作区。模型通过道引 AI Gateway 读取压缩抽样画面，未抽样的内容不应被声称已经逐帧核对。
- 各账号/空间拥有独立资料、素材、计划和结果。内置媒体能力继承有效道引账号访问，不扩大通用代码执行的现有准入范围。
- 原素材、计划、分析和结果事件不可变。上传重试按块验证内容；同一计划的重复渲染返回原成片或原状态，不在失败后覆盖结果或隐式重跑。

## 部署与验证

需要同步 Harness runtime/UI、资源服务及主平台的 Harness 工具契约与抽样画面转发逻辑。主平台提供第一方`campfire-speech`接口，资源服务用`HARNESS_MEDIA_PLATFORM_URL`与`HARNESS_MEDIA_SERVICE_TOKEN`调用（仅主平台服务凭据，禁止供应商密钥）。媒体镜像以明确 digest 配置在资源服务和执行器的 `HARNESS_RUNTIME_IMAGES.media`；保留其他运行环境配置。主平台设置 `AGENT_YINGHUO_ENABLED=0`，防止旧远程工具进入工作台。原营火服务和数据库无需修改或迁移。

只进行小样本真实模型/真实上传/真实工具/持久化验证；静态检查和打包不等于 Agent 验收。生产验收结果单独记录精确 revision、实际环境、模型、输入、工具、保存结果与限制。

高清实拍完整制作的生产运行时限目前显式设置为`DAOYIN_CLOUD_RUN_TIMEOUT_MS=600000`（十分钟有界上限），单轮模型调用仍最多12次。默认五分钟曾实际中止东北荟渲染，不能把这个被取消的任务视为生成成功。禁止新配音不等于禁止用已有音轨渲染；失败/取消后先查原计划事实，不重跑已有render.started的计划。
