# 工作台业务插件

插件入口位于左侧“插件”和输入框左下角“＋”。插件页支持按名称、说明和功能搜索；选择已接入插件后返回会话，保留当前草稿。待接入项展示业务能力，不提供虚假的安装或启用按钮。

## 所有插件的默认权限规则

登录后，所有已接入业务插件自动获得该账号在当前空间内已有的完整业务权限，覆盖读取、写入、生成和管理。以后接入的插件采用相同规则，无需逐插件授权、勾选范围、人工签发或粘贴凭证，不设置额外的 Agent 权限子集。已有账号连接自动复用；外部服务缺少有效连接时只完成该服务必要的登录。完整权限的定义、业务规则与实现边界见 [ADR-0012](adr/0012-first-party-account-access.md)。

## 选择与执行

`packages/ui/src/cloud/plugins.ts` 是界面盘点清单，不签发权限。平台适配器区分 `company-public` 和 `saishi-readonly` Profile；公开空间工具仍只有 `search_company_knowledge`。当前源码的第一方赛事入口继承已登录账号在当前租户的业务读取范围，不需要再次授权，服务端继续验证账号与资源归属。入口、配置及验收边界见 [赛事插件](SAISHI-PLUGIN.md)。

已有会话按服务端返回的 profileId 显示当前插件。新会话提交前校验服务端实际 Profile 与选择一致，不一致时停止模型提交。未识别的 Profile 不回退成官网知识；待接入 ID 不可选择。不通过改提示词、前端勾选、访客 Token 或借用官方付款身份开放短剧写入。

当前每个会话只绑定一个 Profile，不支持任意组合或移除会话工具。同一可用插件内选择保留会话、草稿和事件；官网与赛事账号空间切换时刷新页面并隔离显示。运行中或提交结果不确定时不能切换。后续所有业务插件遵循 [同账号完整权限规则](adr/0012-first-party-account-access.md)，读写、生成与管理都不增加逐插件授权；未接入的工具仍需实际实现。

## 短剧下一步接线

现有短剧 MCP 提供能力发现、受控业务调用、媒体上传、视频工作流、任务查询/等待和审计。接入时从登录身份自动解析个人或企业空间、完整业务权限、项目资源和付款归属，再把任务与作品结果返回同一 AgentEngine。保留写操作幂等性与原有业务交易规则，不增加插件授权或重复确认已明确发出的操作。工作台插件目录本身不完成这些接线。
