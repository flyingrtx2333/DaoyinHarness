## 账号与刷新

账号数据按可信授权平台、租户 ID 和用户 ID 派生独立命名空间；显示名称、请求体和模型参数都不能指定账号身份。隔离覆盖会话目录、JSONL 事件、记忆、上下文压缩、任务编排、一次性权限与最近工作区。登录/退出在运行时空闲时重建服务并轮换 cookie、CSRF 与工作区版本，关闭旧事件连接；模型调用前后核对当前身份。

**旧 local 历史保留在原目录，不会自动归属或复制进某个 OAuth 账号。** 升级后账号会话列表可能为空，但原始记录没有删除。历史导入需要单独设计和明确授权。物理工作区仍是用户选定的文件夹，账号命名空间不是操作系统沙箱。

令牌刷新区分临时 HTTP/网络故障与已确认的 invalid_grant。429、5xx、网络错误、响应异常不清空凭据。共享刷新不受单个调用者取消影响；通过身份代次检查与串行凭据写入，阻止迟到的回调/刷新重新激活已退出的登录。增加超时、响应大小限制、禁止凭据请求重定向、返回身份一致性校验与 DPAPI 加密文件的临时写入替换。凭据存储仍只实现 Windows，不能据此声称跨平台认证已经完成。

设计依据见 [ADR 0005](adr/0005-account-runtime-namespaces.md)。
